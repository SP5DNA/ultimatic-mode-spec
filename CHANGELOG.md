# Revision history

## 2026-11-01

Clarified C.2a as an informative historical example and recommended current-type re-closure suppression for software implementations. Both variants remain accepted. No changes to the reference code or timing diagrams.

## 2026-10-20

Accepted both current-type re-closure policies, requiring implementations to document their choice. Added the two-tap example C.2a, a policy selector in the reference code, and checks for both variants. The reference default remains suppression.

## 2026-10-19

Specified pending-request order, coalescing and exact element-boundary timing. Updated the reference code and timing examples, and added executable reference checks. Implementations based on earlier revisions should review Sections 5–10.
